SBCPUFloating V2.9.5.4 GameOverlay Real Rotation Fix

核心修复：
1. 删除 SpringBoard 内旧的 GameBannerView，避免与独立游戏层重复绘制。
2. 游戏内通知不再创建独立 UIWindow。
3. SBCPUGameOverlay 直接挂到游戏自己的正常 UIWindow 上，因此游戏强制横屏时，
   胶囊跟随游戏窗口一起旋转，不再依赖 UIDeviceOrientation。
4. 横屏固定为左侧约 82pt 宽的竖向黑色圆角胶囊。
5. 只旋转文字标签，不旋转胶囊本体，避免出现“大横条 + 倒置文字”。
6. overlay 及其子视图均不接收触摸，不影响游戏操作。
7. 仍使用 SpringBoard -> plist + Darwin notify 的跨进程通知方式。

测试目标：
QQ飞车手游进入实际游戏横屏后，收到 TIM/微信/QQ 通知时，应出现类似参考视频的左侧竖向黑色胶囊，
通知显示约 4 秒后自动收起。
