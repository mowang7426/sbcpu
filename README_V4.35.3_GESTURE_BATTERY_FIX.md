# SBCPU V4.35.3 — Battery Spacing + Gesture Polish

Changes from V4.35.2:
- Battery column width reduced from 52pt to 48pt.
- Battery text starts 2pt closer to the icon; inter-column gap reduced by 1pt.
- Single tap and double tap now provide light haptic feedback.
- Gesture recognizers no longer all recognize simultaneously; pan/long-press/tap conflicts are reduced.
- Existing single-tap/double-tap failure relationship is preserved, so double-tap remains the settings action.
- Charging, smart-charge, CH0I/CH0C and native Liquid Glass logic are otherwise unchanged.
