SBCPUFloating V2.9 — ChargeBoost merged test

This build keeps the power-optimization monitoring from fixed4 and adds an experimental
ChargeLimit=100 write while the "充电增强（实时验证）" switch is enabled.

Important:
- ChargeLimit is a charging TARGET, not a direct current/voltage/power control.
- No ChargeCurrent/ChargeRate forcing was added.
- The original ChargeLimit is saved when readable and restored when the switch is disabled.
- Existing temperature protection remains enabled.
- Real battery-side power remains Voltage × Amperage.
- AdapterDetails.Watts remains separate and is not treated as battery-side power.

The source file supplied in the conversation does not contain a ChargeCurrent force implementation;
its charging-related low-level code uses ChargeInhibit for temperature protection. Therefore this
is an experimental target-limit test, not a guaranteed fast-charge unlock.
