# SBCPU V4.31 — Smart Charge Recovery + Floating UI Fix

基于 V4.30 Smart Charge Direct CH0I。

## 修复 1：回充下限失效
V4.30 在 CH0I=1 后，AppleSmartBattery/IOPMPowerSource 的 ExternalConnected/charging 可能变成 false。
原状态机先执行“无外部电源”安全门，导致 85% 停充后跌到 82/83% 时根本到不了“<= 回充下限”的恢复分支。

V4.31 把智能回充判断提前：
- 智能停充开启
- 没有手动阻止充电/外部供电
- 电量 <= 回充下限
- 直接清 CH0I=0
- 再重新采样电源状态

即使 daemon 重启导致内存里的 gLimitBlocked 丢失，只要检测到 CH0I 仍为 1 且电量已到下限，也会执行恢复。

## 修复 2：浮窗充电后电量区域/整体突然变窄
V4.30 使用 CH0I 停充后 `IsCharging=false`，浮窗布局因此隐藏充电电流/底部状态区域，导致整个浮窗宽度突然缩小，电量区域看起来异常变窄。

V4.31：
- 当 daemon 报告智能 CH0I 停充时，浮窗仍保持充电布局宽度。
- 停充期间浮窗电流显示固定为 `0 mA`（表示“充电输入已阻断”，不是电池负载电流为零）。
- 电量栏宽度从 44 调整到 52，避免百分比/附加容量文字过度压缩。
- 智能停充状态同时识别 CH0I (`powerBlocked`) 与 CH0C (`chargeBlocked`)。

## 测试
建议：上限 85%，回充下限 83%。
1. 83~84% 插着充电器 → 正常充电。
2. 到 85% → CH0I=1，停止外部供电。
3. 降到 83% → 必须自动 CH0I=0 并恢复充电。
4. 观察浮窗：停充期间宽度保持，不应突然缩成很窄的电量区域。
5. 暂不开启“覆盖 OBC”。
