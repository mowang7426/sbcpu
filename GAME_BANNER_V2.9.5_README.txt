SBCPUFloating V2.9.5 - GameBanner SpringBoard Global Overlay Test

本版重新处理“游戏内通知”问题。

核心变化：
1. 删除 V2.9.4 的 GameOverlay.dylib / GameOverlay.xm 跨进程方案。
2. 游戏内通知直接由 SpringBoard 的现有全屏 SBCPUWindow 显示。该窗口本身已经能覆盖游戏并显示 CPU/FPS，因此不再依赖游戏 App 沙盒读取共享文件。
3. 通知 Banner 与 CPU 浮窗分离：Banner 是顶部独立黑色胶囊，不会塞进 CPU 浮窗。
4. Banner 不接收触摸，游戏操作继续由游戏处理。
5. 支持微信 / QQ / TIM，正文一行，3.5 秒自动消失。
6. 横竖屏变化时重新计算顶部位置，不主动改变游戏方向。
7. 保留原来的 CPU/FPS/电量/温度/电流、通知历史、设置、Mitigation 等功能。

第一阶段测试目标：
TIM/微信/QQ 收到消息
-> 游戏画面顶部出现黑色圆角 Banner
-> CPU 浮窗继续正常显示
-> 游戏触摸不受影响
-> 约 3.5 秒后 Banner 自动消失

注意：
本版为了先验证“SpringBoard 全局 Overlay 是否能稳定覆盖游戏”，暂时不主动屏蔽系统原生通知 Banner。测试时如果同时看到系统白色 Banner + 本插件黑色 Banner，这是预期的第一阶段现象。确认黑色 Banner 稳定出现后，再处理原生 Banner 的隐藏和点击跳转。
